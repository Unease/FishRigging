# FishRigging
A mod is only meant to be for use with non-playback TASes. Using it for other purposes is considered as cheating. This mod lowers the fishing wait time to as soon as possible *when TASmod is installed*. This is basically a port of the old [FishRigging](https://github.com/ScribbleTAS/FishRigging) made by Scribble for use with the new launcher and mappings.

# Installation
This mod requires [TASmod](https://github.com/MinecraftTAS/TASmod) to be installed to properly work. It also requires an instance created using [Orinthe CLI](https://ornithemc.net/download/). In order to create the instance, download the program and execute it from the command line with the argument `prism --minecraft-version VERSION --loader-type fabric --gen 2`. The `--loader-type fabric` and `--gen 2` arguments are **required** for both TASmod and FishRigging to work.
